# Using and deploying the application

## Personal computer

Download the repository ZIP from GitHub, extract it, and open `prototype/budget-dashboard-new.html` in a current browser. Windows users can use Edge, Chrome, or Firefox. macOS users can use Safari, Chrome, or Firefox.

No separate installation is required for the browser version.

## Mobile

Open the application in a mobile browser. The layout adapts to smaller screens. Landscape orientation is recommended for wide transaction tables and charts.

The current application is a web application and is not yet a separately installed Android or iOS app.

## Shared hosting

A future shared deployment should use one supported secure storage service, HTTPS, protected configuration, server-enforced household roles, backups, monitoring, and tested recovery procedures. Do not publish real credentials in the HTML file or repository.
