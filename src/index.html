How the totals are worked out

So the numbers can be checked against the spreadsheet.
Income — actually received on rows where Type is INCOME.
Expenses — spent on Type EXPENSE. Loan repayments — Type LOAN. Savings — Type SAVING.
Balance — income minus expenses minus loan repayments minus savings. Each row counts once, so nothing is double counted.
Total budget and total spent cover outflow only; income rows are left out so the two are comparable.
Paid — spent on rows marked PAID. To be paid — the budgeted amount on rows marked TO BE PAID, since nothing has left the account yet.
